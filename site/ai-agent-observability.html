AI coding agent observability starts with local logs.

agenttrace reads the session files your coding agents already write and turns them into token cost, tool failure, latency, anomaly, health, diff, and CI evidence without a hosted backend.

What AI agent observability should answer.

Traditional logs show that something happened. Coding-agent observability should show why a run got expensive, where tools failed, how long the agent stalled, and whether the next pull request should trust the result.

Token cost tracking agenttrace --overview -f json
Tool failure analysis agenttrace --overview -f html -o agenttrace-overview.html
CI health gate agenttrace --overview --fail-under-health 80 --fail-on-critical --max-tool-fail-rate 15

Local-first, framework-light, source-aware.

agenttrace is built for developers who want AI coding agent observability without sending prompts, code, or private logs to a hosted dashboard. It supports Claude Code, Codex CLI, Gemini CLI, Qwen Code, Cline, Aider, Cursor exports, Hermes Agent, OpenCode, OpenClaw, Oh My Pi, Kimi CLI, Copilot-style logs, and generic JSON/JSONL traces.
