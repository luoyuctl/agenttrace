agenttrace turns local coding-agent logs into a fast TUI, shareable HTML reports, health scores, anomaly evidence, and CI gates. No hosted backend. No prompt upload.

Start with the worst run, not the loudest guess.

The TUI opens on the operating picture: cost, health, latency, recent anomalies, and the sessions most likely to waste human review time.

0 Overview

See the fleet.

Sessions, tokens, cost, error rate, P95 latency, health score, recent anomalies, and top agents.

1 Session List

Rank the waste.

Sort by health, cost, or turns; filter by source, model, anomaly, text, or health threshold.

2 Detail

Inspect evidence.

Primary issue, impact, evidence, next action, loop analysis, tool warnings, and cost alerts.

3 Diag / 4 Diff

Ship the fix.

Fingerprint loops, tool latency, context pressure, large params, rare tools, and side-by-side diffs.

Use the same evidence locally and in CI.

Run the TUI while debugging. Export Markdown for PRs. Attach HTML reports to builds. Fail CI when agent health drops or tool failures spike.

Shareable report agenttrace --overview -f html -o agenttrace-overview.html
PR comment agenttrace --overview -f markdown -o agenttrace-overview.md
Build gate agenttrace --overview --fail-under-health 80 --fail-on-critical --max-tool-fail-rate 15
