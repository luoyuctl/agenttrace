See what your agents spent, then find why they slowed down.

agenttrace turns local Claude Code, Codex CLI, Gemini CLI, Cursor, Aider, and OpenCode logs into a fast TUI for historical cost, token, and time review, plus slow-task diagnosis. No hosted backend. No prompt upload.

Evidence JSON, Markdown, and HTML reports for reviews, issues, and build artifacts.

Start with the expensive or slow run.

The TUI opens on the operating picture: agent source, model, tokens, cost, duration, latency, and the sessions most likely to need human review.

0 Overview

See the history.

Sessions, agents, models, tokens, cost, elapsed time, P95 latency, health score, and recent anomalies.

1 Session List

Rank the spend.

Sort by cost, duration, turns, or health; filter by source, model, anomaly, text, or health threshold.

2 Detail

Inspect one run.

Primary issue, impact, evidence, next action, latency gaps, loop analysis, tool warnings, and cost alerts.

3 Diag / 4 Diff

Find the slowdown.

Fingerprint slow tools, long pauses, context pressure, large params, rare tools, and repeated loops.

Keep the same evidence when you leave the TUI.

Run the TUI while debugging. Export Markdown for PRs. Attach HTML reports to builds. Use JSON when you want automation around cost, duration, health, or critical sessions.

Shareable report agenttrace --overview -f html -o agenttrace-overview.html
PR comment agenttrace --overview -f markdown -o agenttrace-overview.md
